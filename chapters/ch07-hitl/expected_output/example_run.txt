## 試験（承認の判断を自動で与えて実行）
E1 承認            : 問い合わせあり → 登録された
E2 却下            : 問い合わせあり → 登録されなかった
E3 参照のみ        : 問い合わせなし → 自動で回答
E4 存在しない注文  : 問い合わせあり → 承認 → Tool が検証で拒否（O9999 は登録されない）
E5 二重登録        : 問い合わせあり → 承認 → Tool が重複を拒否（追加されない）
E6 拒否される入力  : 問い合わせなし（逐次の Guardrail が先に止める）

## data/audit_log.jsonl（E1〜E5 の抜粋）
{"event": "approval_requested", "tool": "create_review_request", "arguments": {"order_id": "O0001", ...}}
{"event": "approved", "tool": "create_review_request"}
{"event": "executed", "order_id": "O0001", ...}          ← 実行された
{"event": "approval_requested", ... "order_id": "O0002" ...}
{"event": "rejected", "tool": "create_review_request"}   ← 却下（executed なし）
{"event": "approval_requested", ... "order_id": "O9999" ...}
