# api の資格情報で、実際のDBに何ができるか
ro: SELECT orders 成功 / DELETE・INSERT・DROP・CREATE は 読み取り専用トランザクションで拒否 / SELECT review_requests は permission denied
rw: SELECT orders 成功 / INSERT review_requests 成功 / DELETE orders は permission denied / DROP は must be owner / CREATE は permission denied for schema public
(agent_ro / agent_rw とも rolsuper = f)
