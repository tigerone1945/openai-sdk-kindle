# OpenAI Agents SDK Kindle — Reader Source

Kindle読者向けのサンプルソースコードです。制作原稿・編集レビューは含みません。

## 使い方
各章の `chapters/chXX-*/README.md` にある実行方法を確認してください。`src/` はコード、`tests/` は検証、`expected_output/` は検証当時の記録です。共通売上CSVは `data/raw/ai_agent_practice_sales.csv` です。

**注意**：AWSを使う章は課金が発生しうるため、READMEとTerraform Planを確認してください。OpenAI APIにも利用料がかかる場合があります。最新の設定・SDK仕様と書籍内の検証時点の情報は異なることがあります。

出版用Snapshotのタグを後で用意します。現段階では `main` の内容を参照してください。
